# Curso _Redux_ con _Vanilla JavaScript_

En esta carpeta encontrarás los códigos del [Curso de _Redux_ con _Vanilla JavaScript_](https://www.youtube.com/watch?v=-vr_VrT6v6c) de [Jonathan MirCha](https://jonmircha.com/): cómo funciona _Redux_, el _store_, el _reducer_ y las acciones en un contador (`index.html`), y un _CRUD_ de tareas contra una _API REST_ hecha con _JSON Server_ (`crud.html`). _Redux_ se carga desde un _CDN_, sin paso de compilación.

```bash
npm install
npm start
```

`npm start` levanta la _API_ en `localhost:3000` con los datos de `db.json`. Después abre `index.html` con un servidor local, como [_Live Server_](https://github.com/ritwickdey/vscode-live-server).
