## Cómo usar los códigos

Clona el repositorio y abre los archivos con un servidor local, como [_Live Server_](https://github.com/ritwickdey/vscode-live-server): los módulos y las peticiones _AJAX_ no funcionan si abres el _HTML_ directo desde tu disco duro.

```bash
git clone https://github.com/jonmircha/youtube-js.git
```

Algunas secciones necesitan algo más:

- **_API REST_ (clases 111 a 120):** el _CRUD_ consume una _API_ falsa en `localhost:5555`, que levantas con _JSON Server_ desde la raíz del repositorio. El curso usa la versión 0; la 1 cambia algunas cosas.

  ```bash
  npx json-server@0.17 --watch assets/db.json --port 5555
  ```

- **_Uploader_ y formulario con _PHP_ (clases 124 a 126 y 128):** `assets/uploader.php` y `assets/send_mail.php` necesitan un servidor con _PHP_, como [_XAMPP_](https://www.apachefriends.org/) o el servidor integrado: `php -S localhost:8000` desde la carpeta `ajax-ejercicios`.
- **Pagos con _Stripe_ (clases 129 a 132):** pon tus llaves de prueba de _Stripe_ en `ajax-ejercicios/assets/stripe-keys.js`.
- **Curso de _Redux_:** su _API_ también corre con _JSON Server_.

  ```bash
  cd youtube-js/redux
  npm install
  npm start
  ```

## Notas

- El curso se grabó entre 2020 y 2021, y el de _Redux_ en 2024. Algunas _APIs_ externas cambiaron desde entonces:
  - **_TheAudioDB_ (clase 137):** su llave de prueba ya no es `1` sino `123`; cámbiala en la _URL_ de `ajax-ejercicios/10_api-canciones.html`.
  - **_SEPOMEX_ (clase 138):** la _API_ que usa `ajax-ejercicios/11_selects-anidados.html` ya no responde; en su lugar puedes usar [_COPOMEX_](https://api.copomex.com/), que con el _token_ `pruebas` devuelve datos de ejemplo.
- Los formularios de contacto mandan los mensajes a mi correo: cámbialo por el tuyo antes de probarlos.
